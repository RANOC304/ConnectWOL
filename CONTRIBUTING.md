# Contributing to ConnectWOL

Open an issue with your operating system, deployment method, and the steps to reproduce the problem. Use sample addresses and MACs when sharing logs, screenshots, or exported data.

For a pull request, follow the [development setup](README.md#development). Run `npm run lint`, `npm run typecheck`, and `npm test`, then describe what you verified. For Wake-on-LAN changes, report packet transmission and hardware wake results separately. Use the test database for automated checks.
